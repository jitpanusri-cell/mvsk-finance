## หน้า "ยืม ส่งคืน เบิก" สาธารณะ (Loanweb)
- ไฟล์ `Loanweb` สร้างอัตโนมัติด้วย `python3 tools/build_loanweb.py` จาก Index/CSS/JS ของระบบการเงิน — ห้ามแก้ตรง
- วางเป็นไฟล์ HTML ชื่อ `Loan` ในโปรเจกต์หน้าเว็บ (Budget) เปิดที่ `?page=Loan&t=loan|return|adv`
- กรอกแล้วพิมพ์อย่างเดียว ไม่บันทึก ไม่ต้องล็อกอิน ชื่อผู้ลงนาม/เลขที่หนังสือแก้ในชีต "ตั้งค่าเว็บ" (director, deputy, finOfficer, accOfficer, docPrefix, area, garudaUrl)
- แก้แบบฟอร์มในระบบการเงินเมื่อไร → รันสคริปต์ใหม่แล้ววาง Loan ทับ

## ส่วน "งานการเงินและบัญชี" บนหน้า finan
- ข้อมูลอยู่ชีต `งานการเงิน` ในชีตเว็บไซต์ (สร้างอัตโนมัติพร้อม 2 รายการเดิม เมื่อเปิดเมนู เว็บไซต์ ในระบบการเงิน)
- คอลัมน์: รหัส | ประเภท (video/pdf) | หัวข้อ | ลิงก์ไฟล์ Drive | ชื่อปุ่ม | ลิงก์ปุ่ม | สถานะ (VISIBLE/HIDDEN) | ผู้บันทึก | แก้ไขล่าสุด | วันที่ (เช่น วันที่ 31 ต.ค. พ.ศ. 2569) — แถวบน = แสดงก่อน
- แก้ผ่านเว็บ: ระบบการเงิน > เว็บไซต์ > แท็บ "งานการเงินและบัญชี" (PrWeb + PrWebUI.html)

## แถบเมนูลอย (Island) ใช้ร่วมกันทุกหน้าเว็บ
- ไฟล์ `Islandweb` → วางเป็นไฟล์ HTML ชื่อ `Island` ในโปรเจกต์หน้าเว็บ เรียกด้วย `<?!= island('Budget'|'finan'|'Supplies'); ?>` (ฟังก์ชันใน Budgetweb.gs)
- แก้เมนูบน/ปุ่มเจ้าหน้าที่ ที่ไฟล์นี้ที่เดียว มีผลทั้ง 3 หน้า
- หน้า Supplies (Suppliesweb) ใช้โครงเดียวกับ finan: เอกสารและแบบฟอร์ม + ประชาสัมพันธ์งานพัสดุ (ข่าวประเภท supplies-alert)
- เอกสารและแบบฟอร์มหน้า Supplies: ชีต `งานพัสดุ` (โครงเดียวกับชีต งานการเงิน ประเภท link) แก้ผ่านเว็บ: ระบบการเงิน > เว็บไซต์ > แท็บ งานพัสดุ

## สไตล์กลาง (SiteCSS)
- `SiteCSSweb` → ไฟล์ HTML ชื่อ `SiteCSS` ในโปรเจกต์หน้าเว็บ ใช้ร่วม finan/Supplies ผ่าน `<?!= include('SiteCSS'); ?>` (ห้ามมี "//" ในไฟล์)
- ฟอนต์เหลือ 2 ชุด: IBM Plex Sans Thai (หัวข้อ/เมนู) + Sarabun (เนื้อหา)
- Loanweb: build_loanweb.py ตัด JS ด้วย tools/slim_js.js (ต้อง `npm i` ในโฟลเดอร์ tools ครั้งแรก) เหลือ ~460 KB

## หน้ากลุ่มงาน (Group) — แผนงาน / ธนาคารโรงเรียน / ควบคุมภายใน / สำนักงาน
- `Groupweb` → ไฟล์ HTML ชื่อ `Group` (ต้นแบบเดียว ใช้ 4 หน้า) เปิดที่ `?page=plan|bank|control|office`
- ข้อความบทบาทหน้าที่อยู่ใน `GROUPS` (Budgetweb.gs) อ้างอิงสไลด์กลุ่มบริหารงบประมาณ
- เอกสาร: ชีต งานแผนงาน / งานธนาคารโรงเรียน / งานควบคุมภายใน / งานสำนักงาน — แก้ผ่านระบบการเงิน > เว็บไซต์ > แท็บ "เอกสารกลุ่มงาน" (เลือกกลุ่มงาน)
- ข่าว: ประเภท plan-alert / bank-alert / control-alert / office-alert
