# กฎการแก้โค้ด (ทุกแชตอ่านก่อนแก้)

- โค้ดฉบับจริงอยู่ที่ GitHub `jitpanusri-cell/mvsk-finance` (private) ไม่ใช่ไฟล์ claude/code/* ในโปรเจกต์นี้ ซึ่งอาจเก่าแล้ว
- ก่อนแก้: add_repo → clone/pull ล่าสุด → อ่านเฉพาะส่วนที่ต้องใช้ (grep/Read ช่วงบรรทัด) ห้ามแก้จากสำเนาเก่าในเครื่อง
- หลังแก้: commit + push ไปที่ repo (ข้อความ commit บอกเมนู/เรื่องที่แก้) แล้วบอกแค่ชื่อไฟล์ที่เปลี่ยน — ไม่ต้องส่งไฟล์ในแชต (ประหยัดโทเคน) ตอบสั้น ๆ
- ห้ามเขียนไฟล์โค้ดลงโปรเจกต์นี้ (เปลือง token ทุกแชต) — ในโปรเจกต์เก็บแค่โน้ตสถานะสั้น ๆ
- ผู้ใช้แก้ใน Apps Script เองแล้ว → ให้ผู้ใช้ส่งไฟล์มา หรือ push ขึ้น repo ก่อนเริ่มงาน
- JS.html: ห้ามมี "//" ในสตริง (Apps Script minifier ตัดทิ้ง)
